# API Reference - Solar EPC CRM

> **Accuracy note:** several items below are aspirational. Verified gaps as of 2026-10-20:
> `GET /dashboard/funnel` does **not** exist (only `summary` and `team`); `GET /quotations/:id/pdf`
> returns generated bytes and never stores a file or returns a signed Supabase URL; `POST /leads/assign`
> ignores `rule` (round-robin / percent split are not implemented); `POST /leads/import/commit` ignores
> split rules sent by the UI (`splits: []`); there is **no** `GET /users` contract documented even though
> the PWA's Admin -> Staff tab calls it, and no `installations`, `documents`, `service_tickets`, `teams`
> or `settings` endpoints exist at all. Endpoints also include `POST /leads/:id/followup`,
> `POST /leads/:id/request-delete` (submits nothing today) and `DELETE /leads/:id`.
> `/auth/login` currently returns a `demo-token-<role>` for the 7 seeded emails **regardless of
> password** - do not expose this API publicly. See [`AUDIT.md`](./AUDIT.md).

Base URL: `/api`
All endpoints except `/auth/login` and `/public/reports/:token` require a Bearer JWT Token passed in the `Authorization: Bearer <token>` header.

## 1. Authentication & Session
- `POST /auth/login`
  - Body: `{ email, password }`
  - Response: `{ user, profile, token, features }`
- `GET /auth/me`
  - Returns authenticated profile with active permissions and scoped feature grants.

## 2. Leads Management
- `GET /leads`
  - Query: `stage`, `owner_id`, `q` (search name/phone/city), `cursor`, `limit` (default 25)
  - Requires feature: `leads`
- `POST /leads`
  - Body: `{ name, phone, email?, city, state, pincode, source, category, monthly_bill, system_kw, notes }`
  - Validates phone deduplication per org.
- `GET /leads/:id`
  - Retrieves lead details including activities, surveys, quotes, and payment history.
- `PATCH /leads/:id/stage`
  - Body: `{ stage: string, note?: string }`
  - Emits event to log in `lead_stage_history`.
- `POST /leads/assign`
  - Body: `{ lead_ids: string[], owner_id?: string, rule?: { type: 'round_robin' | 'percent_split', target_ids: string[] } }`
  - Requires role: `super_admin | sales_admin`
- `GET /leads/staff-workload`
  - Returns eligible staff members (`sales_admin`, `sales_exec`, `telecaller`, `surveyor`, `super_admin`) with current active lead counts, role, email, and department.
  - Requires role: `super_admin | sales_admin`
- `POST /leads/allocate/preview`
  - Body: `{ lead_ids?: string[], select_all_matching?: boolean, filter_criteria?: BulkFilterCriteriaDto, target_user_ids: string[], allocation_mode: 'single' | 'equal_split' | 'custom_quantity' | 'round_robin', custom_allocations?: [{ userId: string, quantity: number }], allow_reassignment?: boolean }`
  - Returns preview metrics: total target leads, unallocated count, list of affected existing owners, and preview breakdown per recipient.
  - Requires role: `super_admin | sales_admin`
- `POST /leads/allocate`
  - Body: Same as preview. Executes transactional chunked bulk allocation (500-1000 records per chunk), updates `leads.owner_id`, and writes immutable audit log entries with batch ID.
  - Requires role: `super_admin | sales_admin`
- `GET /leads/allocate/history`
  - Returns past allocation audit trail batches with operator details, timestamp, rule type, recipient breakdown, and affected lead counts.
  - Requires role: `super_admin | sales_admin`


## 3. Bulk Import & Splitting
- `POST /leads/import/preview`
  - Multipart file (Excel/CSV). Returns column mappings and first 10 rows validated with formula sanitization.
  - Requires feature: `bulk_import`
- `POST /leads/import/commit`
  - Body: `{ file_id, mappings, split_rules: [{ category, target_user_id, percent }] }`
  - Processes batch using streaming parser.

## 4. Deletion Workflow
- `POST /deletion-requests`
  - Body: `{ entity: 'lead' | 'quotation', entity_id: string, reason: string }`
- `GET /deletion-requests`
  - Requires role: `super_admin | sales_admin`
- `POST /deletion-requests/:id/decide`
  - Body: `{ approved: boolean, note?: string }`
  - If approved, sets `deleted_at = now()` on target record and writes audit entry.

## 5. Quotations & Subsidy
- `POST /quotations`
  - Body: `{ lead_id, kw, panel_brand, inverter_brand, custom_items?: [] }`
  - Computes blended GST (8.9%), PM Surya Ghar subsidy slab, net cost, and 25-yr solar ROI.
  - Generates number `KS/YYYY-YY/XXXX`.
- `GET /quotations/:id/pdf`
  - Streamlines PDF generation using `pdfmake` and returns signed Supabase storage URL.

## 6. Payments
- `GET /payments/lead/:leadId`
  - Lists milestone breakdown (Booking, Advance, Milestone, Final) and total outstanding.
- `POST /payments`
  - Body: `{ lead_id, quotation_id, type, amount, due_date, paid_on?, mode, ref_no }`

## 7. Dashboards & Analytics
- `GET /dashboard/summary`
  - Query: `view = 'company' | 'my'`, `from`, `to`
- `GET /dashboard/funnel`
  - Funnel stage counts and drop-off analytics.
- `GET /dashboard/team`
  - Team conversion rates and achievement against monthly target.

## 8. Exports & Sharing
- `GET /exports/pipeline.xlsx`
  - Streams Excel file using `exceljs`.
  - Requires feature: `export_excel`
- `GET /exports/pipeline.pdf`
  - Generates executive pipeline summary.
  - Requires feature: `export_pdf`
- `POST /reports/share`
  - Body: `{ report_type, filters, expires_in_days }`
  - Generates expiring token.
- `GET /public/reports/:token`
  - Public read-only endpoint with masked PII.
